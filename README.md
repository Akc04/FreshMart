# FreshMart - Online Grocery Store

A modern grocery shopping app built with Next.js, TypeScript, and Tailwind CSS.

## Features
- 🛒 Browse 24 products across 6 categories
- 🔍 Search & category filtering
- ➕ Add to cart with quantity controls
- 💰 Order summary with free delivery over ₹500
- 📋 Checkout with form validation
- ✅ Order confirmation

## Tech Stack
- Next.js 16 (Static Export)
- TypeScript
- Tailwind CSS
- Lucide React Icons

## Run Locally
```bash
npm install
npm run dev
```

## Deploy
This project is configured for GitHub Pages deployment via GitHub Actions.
